# The Hardest Challenge

Geometry Dash tarzı, açık kaynak bir platform oyunu.

## Oyun Hakkında
Engellere çarpmadan ilerlemeye çalıştığın, hızın giderek arttığı bir oyundur. 
Zıplamak için ekrana dokun veya boşluk tuşuna bas.

## Kostümler
- **Klasik:** Dengeli hız ve zıplama.
- **Neon:** Daha hızlı, daha küçük.
- **Mor:** Daha yavaş, daha yükseğe zıplar.
- **Kan:** Daha büyük, güçlü zıplama.
